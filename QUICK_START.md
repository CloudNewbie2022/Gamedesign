# 📚 Reading Habit Tracker - QUICK START

## 🚀 **Your App is Ready!**

### **One-Command Start**
```bash
npm run quick-start
```

### **Manual Start (Two Terminals)**
```bash
# Terminal 1 - Backend
npm start

# Terminal 2 - Frontend  
cd frontend && npm start
```

## 🌐 **Access URLs**
- **App**: http://localhost:3000
- **API**: http://localhost:4000  
- **Health**: http://localhost:4000/health

## 🎮 **How to Play**

### **1. Register/Login**
- Create account with username, password, email
- Choose your favorite book genre
- New users start with **game locked**

### **2. Unlock the Game** 
- Import 90 days of reading data, OR
- Use the stats import feature
- Once unlocked, access all trading features

### **3. Track Reading**
- Log daily pages read
- Build reading streaks
- View your reading portfolio

### **4. Trade with Others**
- Buy/sell shares in other readers
- Monitor reading performance
- Compete in 30-day cycles
